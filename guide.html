ご利用案内이용의 안내

설농체Seolnong · Regular 1.003

ハングルの見出し用書体です。案内板や短い文章にお使いください。

한글의 표시용 글꼴입니다. 안내판이나 짧은 문구에 사용해 주십시오.

インストール설치

ZIPを解凍し、TTFファイルをOSのフォント管理機能でインストールします。書体名は、韓国語環境では「설농체」、英語環境では「Seolnong」です。

ZIP을 풀고 TTF 파일을 운영체제의 글꼴 관리 기능으로 설치합니다. 글꼴 이름은 한국어 환경에서는 ‘설농체’, 영문 환경에서는 ‘Seolnong’입니다.

배포 파일과 용도
ファイル파일用途용도
Seolnong-Regular.ttfインストール用설치용

ZIPには、使用案内のREADME.txtとライセンス原文のOFL.txtも入っています。

ZIP에는 사용 안내인 README.txt와 라이선스 원문인 OFL.txt도 들어 있습니다.

収録文字수록의 문자

  • 現代ハングル音節 11,172字현대 한글 완성 음절 11,172자
  • 現代の結合字母 67字・互換字母 51字현대 조합 자모 67자·호환 자모 51자
  • 基本ラテン文字・数字・記号 95字（ASCII）기본 라틴 문자·숫자·기호 95자(ASCII)
  • 中点、ダッシュ、引用符、括弧、円・ウォン記号、案内の記号、斜めの矢印など가운데점, 대시, 따옴표, 괄호, 엔·원화 기호, 안내의 기호, 비스듬한 화살표 등
  • 全角英数字・記号、℃・㎡・㎞・㎝・㎜・㎏・ℓなど전각 영숫자·기호, ℃·㎡·㎞·㎝·㎜·㎏·ℓ 등

太さはRegularの1種類です。漢字・かな・古ハングルの組み合わせには対応していません。日本語を併記するときは、別の日本語書体を指定してください。

굵기는 Regular 한 종류입니다. 한자·일본어 가나·옛한글 조합은 지원하지 않습니다. 일본어를 병기할 때는 별도의 일본어 글꼴을 지정해 주십시오.

ss01はㅎとㅊを一緒に切り替えます。初声・終声・複合終声・単独字母に適用され、「찮」のように両方が入る文字でも一緒に変わります。

ss01은 ㅎ과 ㅊ을 함께 바꿉니다. 초성·받침·겹받침·독립 자모에 적용되며, ‘찮’처럼 두 대상이 들어간 글자도 함께 바뀝니다.

アプリのOpenTypeスタイルセットで「Upright tops / 세로 꼭지 ㅎ·ㅊ」を選びます。対応していないアプリでは基本形が表示されます。

앱의 OpenType 스타일 세트에서 ‘Upright tops / 세로 꼭지 ㅎ·ㅊ’를 고릅니다. 지원하지 않는 앱에서는 기본형이 표시됩니다.

機能の名前や選び方は、アプリによって異なります。数字と縦書きは、紹介ページの見本でも試せます。

기능의 이름이나 고르는 방법은 앱에 따라 다릅니다. 숫자와 세로쓰기는 소개 페이지의 견본에서도 시험할 수 있습니다.

ウェブで使う웹에서 쓰다

WOFF2を読み込み、言語ごとに書体を指定します。ファイルの場所は、ご自分のサイトに合わせて変更してください。

WOFF2를 읽고 언어마다 글꼴을 지정합니다. 파일의 장소는 자신의 사이트에 맞춰 바꿔 주십시오.

@font-face {
  font-family: "Seolnong";
  src: url("Seolnong-Regular.woff2") format("woff2");
  font-weight: 400;
  font-style: normal;
  font-feature-settings: "ss01" 0;
}

.sign {
  font-synthesis: none;
}
.sign:lang(ko) {
  font-family: "Seolnong", sans-serif;
}
.sign:lang(ja) {
  font-family: "Kosugi Maru", sans-serif;
}
.sign:lang(en) {
  font-family: "Arimo", Arial, sans-serif;
}

ss01を1にすると縦の線、0にすると基本形になります。上の例では、字形の切り替えをソルロン体の@font-faceだけに指定しています。

ss01을 1로 하면 세로 꼭지, 0으로 하면 기본형이 됩니다. 위 예시에서는 자형의 전환을 설농체의 @font-face에만 지정하고 있습니다.

数字と縦書き숫자와 세로쓰기

.numbers {
  font-variant-numeric: proportional-nums slashed-zero;
}
.vertical-sign {
  writing-mode: vertical-rl;
  text-orientation: mixed;
}

等幅の数字には tabular-nums を使います。縦書きでは、ブラウザーが必要な字形を選ぶので、vert や vrt2 を手動で指定する必要はありません。

같은 폭의 숫자에는 tabular-nums를 씁니다. 세로쓰기에서는 브라우저가 필요한 자형을 고르므로 vert나 vrt2를 수동으로 지정할 필요는 없습니다.
