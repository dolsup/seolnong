# 함께 사용하는 글꼴

- **Kosugi Maru Regular**: 일본어 표기. [원본](https://github.com/googlefonts/kosugi-maru), Apache License 2.0. 원본 TTF를 WOFF2로 변환했으며 자형·메트릭·수록 문자·이름은 유지했습니다. 저작권과 변환 고지는 `KosugiMaru-NOTICE.txt`에 있습니다.
- **Arimo Regular**: 영문 표기. [원본](https://github.com/googlefonts/arimo), SIL Open Font License 1.1. 원본 가변 글꼴의 weight 400을 정적 WOFF2로 변환했습니다.

이 글꼴들은 소개 페이지에만 사용하며 설농체 다운로드 ZIP에는 포함하지 않습니다.
각 라이선스 전문과 저작권 고지는 이 폴더의 동봉 파일을 따릅니다.
