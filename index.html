この書体について이 서체에 대하여

大阪の「雪濃湯」の看板と、対馬の店内のハングル案内をもとに作りました。「ト」に似たㅏ、低く横に広がるパッチム。そこで見つけた形を、11,172字のハングルに展開しています。

오오사까의 ‘설농탕’ 간판과, 쓰시마 가게 내부의 한글 안내 표기를 바탕으로 만들었습니다. ‘ト’와 닮은 ㅏ, 낮고 옆으로 퍼지는 받침. 거기에서 발견한 모양을, 11,172자의 한글에 전개하고 있습니다.

このページでは、ハングルはソルロン体、日本語は Kosugi Maru、英字は Arimo を使っています。

이 페이지에서는, 한글은 설농체, 일본어는 Kosugi Maru, 영자는 Arimo를 쓰고 있습니다.

@font-face {
  font-family: "Seolnong";
  src: url("Seolnong-Regular.woff2") format("woff2");
  font-feature-settings: "ss01" 0;
}

.sign:lang(ko) {
  font-family: "Seolnong", sans-serif;
  font-synthesis: none;
}
.sign:lang(ja) {
  font-family: "Kosugi Maru", sans-serif;
}
.sign:lang(en) {
  font-family: "Arimo", Arial, sans-serif;
}

Kosugi Maru と Arimo は別に読み込んでください。ss01 を 1 にすると、ㅎ・ㅊの上の線が縦になります。

Kosugi Maru와 Arimo는 따로 읽어 주십시오. ss01을 1로 하면, ㅎ·ㅊ 위의 선이 세로가 됩니다.
